Sudoku is a minimalist, responsive web Sudoku platform built with React 19, Vite, and an algorithmic backtracking generator. Designed with a clean dark aesthetic and standard 9x9 grid geometry, the application delivers a seamless puzzle-solving experience featuring real-time conflict validation, smart peer and matching digit highlighting, pencil notes mode, step-by-step move undo, contextual hints, stopwatch timer tracking, and complete keyboard navigation.

---

## Key Features

### Puzzle Generation & Validation
- **Backtracking Engine & Unique Solution Guarantee:** Built on a randomized recursive backtracking algorithm ensuring valid 9x9 puzzle boards and verifying exactly one unique logical solution per generated game (`src/utils/sudokuGenerator.js`).
- **4 Balanced Difficulty Tiers:** Calibrated clue distributions catering to all skill levels: Easy (38 clues), Medium (32 clues), Hard (28 clues), and Expert (24 clues) (`src/utils/sudokuGenerator.js`, `src/components/GameHeader.jsx`).
- **Real-Time Conflict Detection:** Dynamic rule enforcement identifying and highlighting duplicate numbers across rows, columns, and 3x3 nonets with clear danger alerts (`src/utils/sudokuGenerator.js`, `src/components/SudokuCell.jsx`).
- **Standard International Grid Geometry:** WPF/WSC-compliant standard 9x9 grid layout with pronounced borders distinguishing internal 3x3 subgrids and high-contrast typography (`src/components/SudokuBoard.jsx`, `src/styles/sudoku.css`).

### Game Controls & Assistance
- **Pencil Notes Mode (`Notes`):** Contextual candidate notation allowing players to jot down numbers 1-9 in a miniature 3x3 grid within empty cells, with automatic pruning upon confirmed digit entry (`src/hooks/useSudoku.js`, `src/components/SudokuCell.jsx`, `src/components/Controls.jsx`).
- **Smart Peer & Digit Highlighting:** Intuitive visual assistance highlighting the active cell, associated row, column, 3x3 box, and all identical digits across the board (`src/components/SudokuCell.jsx`, `src/styles/sudoku.css`).
- **Step-by-Step Move Undo:** State-restoring undo capability preserving previous board states, active pencil notes, and mistake counters (`src/hooks/useSudoku.js`, `src/components/Controls.jsx`).
- **Contextual Logical Hint:** Intelligent solver assistance revealing accurate cell placements on demand to help players overcome logical deadlocks (`src/hooks/useSudoku.js`, `src/components/Controls.jsx`).
- **Comprehensive Keyboard & Touch Controls:** Complete desktop keyboard shortcuts (Arrow keys/WASD for navigation, 1-9 for inputs, Backspace/Delete to erase, N for notes, U for undo, H for hint, Space to pause) paired with an on-screen responsive touch numpad (`src/App.jsx`, `src/components/NumberPad.jsx`).

### Time Tracking & Outcome Resolution
- **Stopwatch Timer with Anti-Cheat Pause:** Precision time elapsed tracking with automatic board obscuration during pauses to preserve game integrity (`src/hooks/useSudoku.js`, `src/components/GameHeader.jsx`, `src/components/SudokuBoard.jsx`).
- **Remaining Digits & Mistake Counter:** Real-time inventory tracking remaining instances of each number (1-9) alongside recorded errors (`src/hooks/useSudoku.js`, `src/components/NumberPad.jsx`).
- **Victory Modal Resolution:** Celebratory completion modal displaying elapsed time, chosen difficulty tier, mistake count, and instant replay controls (`src/components/WinModal.jsx`).

## Technology Stack

- **Frontend:** React 19, JavaScript ES6+, HTML5 Semantic Elements.
- **Puzzle Rules & Logic:** Pure ES6+ Backtracking Algorithm, Fisher-Yates Shuffle, Unique Solution Validator (`src/utils/sudokuGenerator.js`).
- **Styling & Design System:** Pure Vanilla CSS3, Custom Properties (CSS variables), Responsive Grid/Flexbox layouts, Plus Jakarta Sans & JetBrains Mono typography.
- **Build & Tooling:** Vite 8.

## Getting Started

### Prerequisites
- Node.js (`^20.19.0 || >=22.12.0`, required by Vite 8)
- Yarn or npm

### Quick Start

```bash
# Clone the repository
git clone https://github.com/thaihadefi/sudoku.git
cd sudoku

# Install dependencies
yarn install

# Run development server
yarn dev

# Build for production / preview the build
yarn build
yarn preview
```
